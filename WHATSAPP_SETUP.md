# WhatsApp Cloud API & SMS Notification Setup Guide

This guide walks you through setting up and verifying **Meta WhatsApp Cloud API**, **Twilio SMS/WhatsApp**, and **MSG91** for FarmRoute Optimizer.

---

## 1. Overview of Notification Architecture

FarmRoute Optimizer sends:
1. **One-Time Password (OTP) verification codes** via both SMS and WhatsApp (`OTP_CHANNEL=both`).
2. **OTP resend** requests via both SMS and WhatsApp.
3. **Registration welcome messages** via both channels.
4. **Plan published & re-plan updates** to all impacted farmers via both SMS and WhatsApp.

Notification channels operate independently:
- A failure on SMS will **not** prevent WhatsApp from attempting delivery.
- A failure on WhatsApp will **not** prevent SMS from attempting delivery.
- Each attempt is recorded individually with provider error codes and timestamps in the database (`notification_log`) and visible in the Admin Console.

## 2. Meta WhatsApp Cloud API Setup

### Step 1: Create a Meta Developer App
1. Go to [developers.facebook.com](https://developers.facebook.com) and log in.
2. Click **My Apps** > **Create App**.
3. Select **Other** as the use case > **Business** as the app type.
4. Give your app a name (e.g., `FarmRoute Notifications`) and select your Meta Business Account.

### Step 2: Configure WhatsApp Product
1. In the App Dashboard, find **WhatsApp** and click **Set up**.
2. Navigate to **WhatsApp** > **API Setup** in the left sidebar:
   - Note the **Phone number ID** (e.g., `105938274619482`).
   - Note the **WhatsApp Business Account ID**.
   - Note the **Temporary Access Token** (valid for 24 hours).
3. Under **To**, select or add your test mobile number (with country code, e.g. `919876543210`) to the recipient whitelist.
   > **Note for Sandbox/Development Mode:** Meta requires test recipient phone numbers to be explicitly added and verified via OTP in the Developer Portal before they can receive template messages.

### Step 3: Create & Submit WhatsApp Message Templates

In Meta Business Manager ([business.facebook.com](https://business.facebook.com)) > **WhatsApp Manager** > **Account Tools** > **Message Templates**:

#### A. OTP Template (`WHATSAPP_OTP_TEMPLATE`)
- **Name:** `farmroute_otp` (or custom name set in `WHATSAPP_OTP_TEMPLATE`)
- **Category:** `AUTHENTICATION`
- **Languages:** English (`en`), Telugu (`te`), Hindi (`hi`), Tamil (`ta`)
- **Code Expiration:** 10 minutes
- **Body:** Auto-generated by Meta for Authentication templates (`{{1}} is your verification code...`).
- **Button:** Add a **Copy Code** button (`sub_type: url` in API).

#### B. Plan Update Template (`WHATSAPP_TEMPLATE`)
- **Name:** `farmroute_plan_update`
- **Category:** `UTILITY`
- **Languages:** English (`en`), Telugu (`te`), Hindi (`hi`), Tamil (`ta`)
- **Body:**
  ```text
  {{1}}
  ```
  *(A single parameter variable `{{1}}` that receives the formatted FarmRoute plan update message).*
- **Sample text for review:**
  `Farmroute: A truck will come to your farm at 1:05 PM to take your 1250 kg of tomato to Mandi 3.`

### Step 4: Temporary Testing Alternative (`hello_world`)
If your custom templates are still under review or pending Meta approval:
- Meta provides a pre-approved template named `hello_world` in all accounts.
- In `backend/.env`, set:
  ```env
  WHATSAPP_PROVIDER=meta
  WHATSAPP_OTP_TEMPLATE=hello_world
  WHATSAPP_TEMPLATE=hello_world
  ```
- **Limitation:** `hello_world` is fixed in English (`en_US`) and does not take variable parameters. It is used solely to verify API token validity and connectivity with Meta Graph API.

### Step 5: System User Permanent Access Token (Production)
For long-term production use:
1. Go to **Business Settings** > **System Users**.
2. Add a System User (Role: `Admin`).
3. Click **Add Assets** > assign your WhatsApp App with `Full Control`.
4. Click **Generate New Token** > select `whatsapp_business_messaging` and `whatsapp_business_management` permissions.
5. Set token expiration to **Never**.
6. Copy this token to `WHATSAPP_TOKEN` in `backend/.env`.

## 3. SMS Configuration (Twilio / MSG91)

### Twilio SMS
1. Sign up at [twilio.com](https://www.twilio.com).
2. Obtain your **Account SID** and **Auth Token** from the Twilio Console.
3. Obtain a Twilio phone number with SMS capabilities (`TWILIO_SMS_FROM`, e.g., `+12055550199`).
4. Configure in `backend/.env`:
   ```env
   SMS_PROVIDER=twilio
   TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   TWILIO_AUTH_TOKEN=yyyyyyyyyyyyyyyyyyyyyyyyyyyyyyy
   TWILIO_SMS_FROM=+12055550199
   ```

### MSG91 SMS (India DLT Compliant)
1. Register on [msg91.com](https://msg91.com) and complete DLT registration.
2. Create Flow templates with a single body variable (e.g. `VAR1`):
   - OTP Flow Template ID -> `MSG91_OTP_TEMPLATE_ID`
   - Plan Update Flow Template ID -> `MSG91_UPDATE_TEMPLATE_ID`
3. Configure in `backend/.env`:
   ```env
   SMS_PROVIDER=msg91
   MSG91_AUTH_KEY=zzzzzzzzzzzzzzzzzzzzzz
   MSG91_OTP_TEMPLATE_ID=1111111111111111
   MSG91_UPDATE_TEMPLATE_ID=2222222222222222
   MSG91_VAR=VAR1
   ```

## 4. Troubleshooting Common Meta WhatsApp Error Codes

| Error Code | Meaning | Resolution |
|---|---|---|
| **190** | Invalid OAuth Access Token / Token Expired | Refresh temporary token or use a Permanent System User Token. |
| **131030** | Recipient phone number not in allowed list | In Development mode, add the recipient mobile number to the Allowed Numbers list in Meta App Dashboard. |
| **132000** | Template does not exist | Verify template name spelling and that the language code (`en`, `te`, `hi`, `ta`) is approved. |
| **132001** | Template is paused or disabled | Review template status in Meta WhatsApp Manager; resolve policy flags. |
| **131026** | Message undeliverable | Ensure the recipient phone number is active on WhatsApp and has the country code prepended. |
| **100** | Parameter mismatch | Verify that body parameter count and button parameter configuration match the approved template. |
